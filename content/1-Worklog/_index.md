This 12-week worklog (15/09/2026 – 29/11/2026) follows a theory-first AWS learning path. Each week focuses on principles, documentation, architecture diagrams, basic setup steps, and commands to understand. Deploying paid resources or running a production workload is not required.

1. [Cloud Fundamentals and AWS Global Infrastructure](1.1-week1/) — 15/09/2026 – 21/09/2026
2. [AWS Account, IAM, STS, CLI, and Budgets](1.2-week2/) — 22/09/2026 – 26/09/2026
3. [Compute: EC2, EBS, and Systems Manager](1.3-week3/) — 28/09/2026 – 02/10/2026
4. [Amazon S3 and Object Storage](1.4-week4/) — 05/10/2026 – 09/10/2026
5. [Networking: VPCs, Subnets, Routing, and Endpoints](1.5-week5/) — 10/10/2026 – 15/10/2026
6. [Databases: Amazon RDS and DynamoDB](1.6-week6/) — 16/10/2026 – 22/10/2026
7. [Serverless: Lambda, API Gateway, and Event-Driven Architecture](1.7-week7/) — 23/10/2026 – 28/10/2026
8. [Infrastructure as Code: CloudFormation and AWS SAM](1.8-week8/) — 29/10/2026 – 04/11/2026
9. [Monitoring, Logging, and Auditing](1.9-week9/) — 05/11/2026 – 10/11/2026
10. [AWS IoT Core, MQTT, and Data Pipelines](1.10-week10/) — 11/11/2026 – 17/11/2026
11. [Security, Cost Optimization, and Well-Architected](1.11-week11/) — 18/11/2026 – 23/11/2026
12. [Capstone: Student Market](1.12-week12/) — 24/11/2026 – 29/11/2026

For every week, the expected evidence is a set of notes, a comparison table or diagram, and self-review questions. AWS credentials, private keys, certificates, and other secrets must never be included in the worklog.
