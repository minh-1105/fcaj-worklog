This 12-week worklog follows a theory-first AWS learning path. Each week focuses on principles, documentation, architecture diagrams, basic setup steps, and commands to understand. Deploying paid resources or running a production workload is not required.

1. [Cloud Fundamentals and AWS Global Infrastructure](1.1-week1/)
2. [AWS Account, IAM, STS, CLI, and Budgets](1.2-week2/)
3. [Compute: EC2, EBS, and Systems Manager](1.3-week3/)
4. [Amazon S3 and Object Storage](1.4-week4/)
5. [Networking: VPCs, Subnets, Routing, and Endpoints](1.5-week5/)
6. [Databases: Amazon RDS and DynamoDB](1.6-week6/)
7. [Serverless: Lambda, API Gateway, and Event-Driven Architecture](1.7-week7/)
8. [Infrastructure as Code: CloudFormation and AWS SAM](1.8-week8/)
9. [Monitoring, Logging, and Auditing](1.9-week9/)
10. [AWS IoT Core, MQTT, and Data Pipelines](1.10-week10/)
11. [Security, Cost Optimization, and Well-Architected](1.11-week11/)
12. [Theory Capstone: IoT Weather Platform](1.12-week12/)

For every week, the expected evidence is a set of notes, a comparison table or diagram, and self-review questions. AWS credentials, private keys, certificates, and other secrets must never be included in the worklog.
